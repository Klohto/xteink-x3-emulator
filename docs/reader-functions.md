# Stock reader tools

`scripts/test-crossink-functions.py` runs the pinned, unchanged CrossInk X3 release through its button UI. Each workflow gets its own real FAT16 card and full ROM boot. It never substitutes a host implementation for a guest function.

```sh
python scripts/test-crossink-functions.py --output local/runs/reader-tools-1
```

Use `--workflows chapter bookmarks clippings fonts lookup` to select workflows, or `--backend /absolute/path/to/qemu-system-riscv32 --rom-dir /absolute/path/to/roms` for a specific backend. The default runs those five offline workflows. `wifi-probe` is an explicit diagnostic mode that follows Home → File Transfer → Join Network and preserves the real initialization failure, registers and MMIO observations if networking is blocked.

Additional replay routes are selected explicitly with `--workflows dictionary percent stablepage footnotes autoturn qr-screenshot completion layout endbook`. Their receipts report each executed postcondition; an available route in the script is not proof that its run passed.

| Workflow | Real guest route and observable postconditions |
| --- | --- |
| `chapter` | Main menu → Select Chapter → second TOC entry. A new rendered page, guest-created section-1 cache and saved spine-1/page-0 progress prove the jump. |
| `bookmarks` | Bookmarks tab → Add Bookmark → View Bookmarks → jump back → Remove Bookmark. The VERSION5 store identifies the original book and position; the jump restores the same pixels. Removing the last bookmark deletes its store, as the stock source specifies. |
| `clippings` | Save Clipping → start word → extend right → finish. The selected highlight changes, a VERSION4 record and `/My Clippings.txt` contain the selected text, and View Clippings → detail → open restores the recorded location. |
| `saved-clipping-jump` | Creates both a bookmark and a clipping through the reader UI, then exits on page2. Home → Saved Items → original book → Clippings → detail → Open must consume the global pending clipping anchor and restore page1 exactly. Saved stores remain unchanged, page1 persists on exit, and a fresh CPU restores the same highlighted reading pixels. |
| `fonts` | Book Options → Font Options → Bitter Preview → Select → 16-point size. The VERSION9 per-book settings and rendered page change. A fresh QEMU CPU boots from only the guest-written flash/card, reopens the book and restores both settings and exact page pixels. |
| `lookup` | A source-compatible synthetic StarDict is present and selected in the fixture. The guest selects a page word, reads its definition, builds its own `.qidx`, records a direct lookup and reopens it through Lookup History. The second successful lookup appends another direct-history entry, matching the pinned source. |
| `dictionary` | Starts with no selected dictionary. Settings tab → Book Dictionary discovers the original StarDict files, saves the chosen per-book path, and performs lookup/history. A fresh CPU reopens the book and performs another definition lookup using the saved selection. |
| `percent` | Go To Percent → ten-percent increment → apply → exit. Changed reading content and saved first-chapter progress establish the jump. |
| `stablepage` | Uses the original synthetic EPUB with its embedded `META-INF/x-locations.json`. The real Stable Page picker increments page1 to2, resolves the declared word boundary and saves spine1/page0. Publisher pagebreak markers alone do not enable this menu. |
| `footnotes` | An EPUB noteref exposes Footnotes → link1. The reader follows `#note-1`, advances to the final note paragraph, and Back restores the exact original page and saved position. Frames retain the visible text for review; the harness does not claim OCR verification. |
| `power-footnotes` | Global Controls → Power Button selects the physical Footnotes shortcut and exposes its conditional return toggle. With return On, a GPIO3 short pulse restores the exact visible origin. The pinned guest then flushes stale pending note progress when that origin was already persisted; this quirk is recorded explicitly. A real TOC jump establishes the Off comparison: on a note page without links, Power must leave refresh count, CRC and raw pixels unchanged. A fresh CPU repeats the saved Off setting and behavior. |
| `autoturn` | Saves a five-second per-book interval, waits for a real timer-driven page refresh, stops through short Confirm, and checks that no further turn occurs over seven virtual seconds. A later Confirm opens the normal menu. The stock path has one active/stopped state, rather than a separate pause state. |
| `qr-screenshot` | An independent zxing-cpp decoder reads the actual captured QR. Its exact bytes must equal the guest's cached page words in serialized order, separated by spaces and truncated at the source-defined UTF-8 boundary. Finder geometry is retained as a separate check. Screenshot saves a complete source-defined 1-bit BMP matching the rotated original ink geometry and restores the visible page after its temporary border feedback. |
| `completion` | Opens per-book Reading Stats, toggles Mark Finished then Mark Unfinished through the Settings tab, validates the VERSION5 store and checks the unfinished state after a fresh CPU boot. Qualifying long reading sessions are tested separately by the library replay. |
| `layout` | Changes line and word spacing, disables text anti-aliasing, changes both margins and alignment, enables hyphenation and forced indents, and disables paragraph spacing through Book Options. The VERSION9 fields and rendered page change; a fresh CPU restores the same settings and exact pixels. |
| `endbook` | Applies 100 percent, accepts the real 99-percent completion prompt by selecting Confirm after its default Cancel row, then advances to the end screen and Home. The completed flag and last visible final-chapter page persist. The end screen itself does not queue a new reading position. |
| `render-options` | Uses an original EPUB image and author CSS. Display/Placeholder/Suppress change both saved settings and committed section profiles; Display must reproduce every decoded image pixel. Publisher markers, embedded CSS and Balanced reading mode are changed through Book Options and survive a fresh CPU boot. The guest's separate `_balanced` section cache verifies the applied mode. |
| `incremental` | Selects Incremental through Book Options, opens an uncached chapter and exits. The guest must commit a valid F3 partial cache with page lookup tables and parse watermark; a fresh CPU restores the exact body and reading position. The full-frame comparison is retained separately because the source-defined page-count estimate can change on reopening. |
| `bookmark-delete` | Creates two real bookmarks, verifies that Cancel preserves their exact bytes, then selects Confirm for Delete All. The absent store persists after a fresh CPU boot. |
| `clipping-multipage` | Extends real selection through a second page, validates the VERSION4 range and exact text export, cancels and executes selected-item deletion. The text export remains append-only, matching the source. |
| `clipping-table` | Selects adjacent words within an original table column. The guest stores an explicit table-selection identifier and exports the selected text; the store and source-defined visible highlight must survive a fresh CPU boot. |
| `statusbar` | Changes Chapter Count, stable pages, percentage visibility/format, progress bar/thickness, title, battery and the XTC-bar preference through Customise Status Bar. The saved global JSON and rendered EPUB footer survive a fresh CPU boot. XTC preference persistence is distinct from the fixed-format reader's display proof. |
| `dictionary-stem`, `dictionary-alt`, `dictionary-fuzzy`, `dictionary-phrase` | Original fixture words drive the actual stem, synonym, suggestion and multiword-selection branches. Their successful history entries must have source-defined T/Y/S/D statuses and the expected resolved word. |
| `dictionary-history` | Tests selected-entry delete cancellation, then genuinely deletes both entries and verifies an empty history file after reboot. The stock UI has no bulk Clear All history action. |
| `dictionary-chain` | Selects words inside actual definitions to follow clock → river → reader. Equal-height original definitions allow Short Back to restore exact pixels without appending history; source-defined long Back exits to the original reader. An earlier unequal-height run is retained: the stock modal intentionally keeps the largest height reached during the chain. All definition bytes are recorded fixture inputs. |
| `dictionary-global` | First opens a real book so the guest creates its configuration directory, then changes the global Dictionary enum. The book inherits it, an explicit per-book dictionary remains active after global None, and Use Global subsequently inherits None. The empty configuration files survive a fresh CPU boot. |
| `sd-font` | Discovers an original complete printable-ASCII CPFONT family and both installed sizes through the real font catalog. Preview/Select applies the SD family; changing14to18pt must display the exact original multi-glyph word bitmap and alter the reading page. The real global SD download-range picker and font/size settings persist after a fresh CPU boot with exact reader pixels. |
| `dictionary-font` | Installed dictionaries expose their distinct font/size controls. A real per-book SD-family override and18pt selection change the displayed definition to exact original ASCII glyphs; closing the definition restores the original reader. The saved override and exact definition pixels survive a fresh CPU boot. |

The button pulses last exactly 400 ms on `QEMU_CLOCK_VIRTUAL`, with a released interval before the next press. Source-defined Preview/Select and menu focus steps are separate actions; the harness does not silently retry an ignored input. Pulse timing is a replay setting, not a calibrated measurement of physical buttons.

The optional QR replay requires an independent host decoder: install `zxing-cpp==3.1.1` in the Python environment used for the replay. The decoder reads a standard-library memoryview of the captured pixels. Other workflows and the emulator launcher retain their standard-library dependencies. If the decoder is unavailable, QR payload acceptance fails explicitly.

Frames are captured with the guest stopped after the native refresh counter remains unchanged and BUSY is inactive for at least one virtual second. The PGM's refresh ID and raw pixel CRC must match QMP. Native host-output counters, contiguous trace sequence numbers and byte counts also establish trace completeness. Where available, the open trace descriptor and pathname must refer to the same linked inode with the same size and position; a replaced pathname remains a strict failure even if its bytes happen to match. EPD errors emitted when the file closes after the last QMP snapshot also invalidate diagnostics. Workflow-specific guest files and screen comparisons establish the UI effect; a quiet framebuffer alone does not prove a particular activity. Screenshot feedback deliberately lasts one second, so its replay requires the subsequent restoration refresh when the border is still visible.

Each `validation.json` records the firmware/source pin, source-file hashes where known, fixture/card/book hashes, exact input events, action hash, frames, asserted effects and diagnostics for every boot. `functional_pass` describes the executed workflow. `strict_pass` additionally requires clean model diagnostics and complete frame traces; the program exits nonzero while those strict gates fail. No unsupported access is waived, and speed selection and physical-output validation remain false.

The Power footnote replay also separates visible return from persisted position. In the pinned source, rendering the already-saved origin skips `queueProgressSave`; the pending note position can remain in `ReaderProgressSaveDebouncer` and be flushed on exit. Its receipt preserves that observed guest behavior with `guest_origin_persistence_correct=false`, and records the explicit TOC navigation used for the later comparison. It does not claim that the guest's origin persistence is correct.

The pinned button-driven EPUB menu has dictionary lookup and lookup history. It has no full-text EPUB Search entry. Orientation, media/display/lock/sleep workflows belong to `test-crossink-display.py`; global settings/library workflows belong to `test-crossink-library.py`; sensor/button-remap workflows belong to `test-crossink-controls.py`.

The dictionary acceptance found a genuine fixture formatter compatibility issue: names with exactly 13 UTF-16 units had an unnecessary empty last VFAT record. Stock SdFat could list those names but could not open them. The formatter now emits the minimum number of records and places a terminator only when space remains. The failing card and native USB evidence are retained locally; the lookup workflow uses the original dictionary filenames with the corrected formatter.

Global Dictionary is an enum in the pinned Settings list. With one installed dictionary, Confirm cycles between None and that dictionary directly. The per-book picker has Use Global and installed dictionaries; it has no separate None override. An empty per-book file falls through to the global path. Before any reader has created `/.crosspoint`, the global setter can fail to open its configuration file; the failed replay is retained and the successful route establishes that directory through genuine reader entry.

The stock registry auto-selects its first dictionary when the global file is absent. The global replay records that transition, explicitly cycles it to None, then selects the dictionary through the real enum. An existing empty global file preserves None.

The font inputs contain original geometric code-cell glyphs for every printable ASCII character, with separate 14pt and 18pt files. They test coverage, registry/bitmap loading, size changes and persistence; they do not represent a natural-language typeface or Unicode/shaping coverage. The source-defined SD Font Size Range filters Manage Fonts downloads. It does not filter already-installed family sizes, which remain selectable. The network replay owns actual manifest/download filtering; an offline range preference alone is not download proof.

Incremental indexing retains a bounded lookahead of five pages. Reader exit commits those pages with version F3 and a consumed/total XHTML-byte trailer. While building, the total-page estimate uses an exponential moving average; reopening a committed prefix extrapolates from its watermark. The replay therefore compares every raw body pixel within source-derived viewport bounds, retains the exact whole-frame difference, and separately checks saved page position. This is an explicit footer-estimate distinction, not a relaxed comparison of reading content.
