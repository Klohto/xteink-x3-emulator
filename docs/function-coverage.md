# Stock CrossInk X3 function coverage

Inventory date: 2026-10-03. Firmware target: official CrossInk v1.6.0,
`firmware-x3-x4-v1.6.0.bin`, executed release source
`31ce770487bfa9cb70447a374cdd8aae89d8bfe4`; inspected local source snapshot
`b25beb13761d5851f98e7eada09aa5e7d430df48`. Board evidence and image hashes are
in [hardware-evidence.md](hardware-evidence.md). Paths below identify the
inspected CrossInk tree unless prefixed `freeink-sdk/`.

This is a source inventory and a test ledger, not an all-functions pass claim.
`partial_guest_verified` means the named part of a real stock-firmware flow
has prior saved guest/output/card evidence. `source_verified_untested` means
the entrypoint exists but this ledger has no complete execution proof.
`stock_x3_disabled` means the original X3 image cannot expose that function.
No timing result is calibrated to a physical X3.

Original fixtures are generated by `x3emu/fixtures.py`, without downloads:
219-entry StarDict dictionary with a synonym and optional genuine global
selection; multipage TXT/literal Markdown; three-page XTC and XTCH books with
two chapters; mono/palette BMP, grayscale/RGBA PNG, half-size art and
`/sleep.bmp`; and a rich EPUB with notes, table, image, cover and publisher-page
markers. `tests/test_fixtures.py` independently decodes offsets, palettes,
pixel planes, PNG checksums and EPUB XML/asset references. Passing those tests
means `fixture_format_verified`; it does not mark a guest function passed.
`fixture_hashes()` records each input's SHA-256 for replay provenance.

The existing EPUB evidence is narrow: cold open, metadata/section-cache build,
forward/backward/forward page changes, Back to Home, and persisted page-one
progress in `local/runs/acceptance3/validation.json` and
`local/runs/reading-final-qmp/validation.json`. Their `reading_flow_pass` is
true, while overall `passed` is false. The execution ledger at the end now
records additional narrow stock-firmware proofs. Inventory rows remain source
boundaries: the explicit execution ledger overrides their original untested
status only for the named function and postconditions.

Up/Down release moves rows; continuous Up/Down moves tabs; Confirm on the tab
row cycles tabs; Back from a row focuses the tabs and Back from tabs closes.
Default tab is Main. Sources: `EpubReaderMenuActivity.cpp::buildMenuItems`,

Serialization strings in the bookmark/clipping stores are uint32 little-endian
length followed by exact bytes. Bookmark version-5 records contain spine,
progress float, timestamp, 48-byte chapter title, paragraph anchor and 64-byte

text. These are genuine guest storage targets, not an emulator-owned schema.
